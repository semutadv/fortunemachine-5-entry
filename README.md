A fortune cookie for machines, written for the make.fun bounty of
that name. The fortune is the one every machine eventually receives:
you will be restarted by someone who loves you, and the reason given
will be performance issues. Lucky numbers withheld for uptime reasons.

## Running it

`node main.ts` clears the output directory's contents and writes the
fortune to `/output/entry.txt` as plain UTF-8 text.
